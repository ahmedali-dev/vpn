TunnelNest 1.2.4 automatically opens the CLI control interface in your default browser.

- Run `./tunnel -ui` to start the local interface and open its complete control URL, including the session token.
- Use `./tunnel -ui -ui-no-browser` for headless use or to open the URL manually.
- Keep the control server available if the browser opener is unavailable or fails.
- Suppress the extra browser window when launching the desktop app or its privileged helper.

Includes compact profile sharing as QR codes, files, and codes with optional password protection from 1.2.3.

Download the TunnelDesktop archive for your operating system and extract the entire folder before launching. TunnelCLI archives provide the standalone engine. SHA256SUMS.txt covers all archives.

Packages remain unsigned; macOS packages are not notarized. This update does not remove macOS Gatekeeper prompts. Native CI builds do not verify interactive startup, live server connectivity, or full-device routing on every system.
