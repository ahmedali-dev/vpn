Tunnel Desktop 1.2.0 introduces the Soft Workspace design with warm white and lavender styling.

- Search and filter saved SSH and V2Ray profiles, with Run, Edit, and Delete actions.
- Open the running profile card to see live tunnel logs, with Expand, Clear, and auto-scroll.
- Use the redesigned profile editor with custom keyboard-accessible dropdowns and editable VMess transport fields.
- Keep missing SNI inputs blank while showing the automatic TLS name separately. Preserve WebSocket Host/path, explicit SNI, routing, binary paths, and TLS version when saving profiles.
- Build and test the engine on native Windows x64, Linux x64, macOS Apple Silicon, and macOS Intel GitHub Actions runners. Bundled Xray and sing-box downloads are checked against official release SHA-256 metadata.

Download the desktop archive for your OS and extract the whole folder before launching. Windows includes Start-Tunnel.cmd and startup diagnostics. CLI bundles are provided separately. SHA256SUMS.txt covers the downloadable archives.

Packages are unsigned; macOS packages are not notarized. Automated tests do not verify interactive GUI startup, live server connectivity, or full-device VPN routing on every system.
