# TunnelNest 1.3.0

- Encrypt saved profile arguments using an OS credential vault or a master password. Add a session-only credentials option and locked-vault controls.
- Preserve profile settings during editing and normalize legacy full-device routing options.
- Keep profiles and the interface under the normal user while a leased administrator helper manages full-device networking.
- Separate SSH host-key trust from TLS compatibility and retain explicitly accepted session keys across reconnects.
- Add bounded SSH operations, continuous connectivity checks, degraded status, and verification after reconnecting.
- Add diagnostic export and native Linux x64/ARM64 tests for TUN TCP capture, IPv6 and DNS.
- Upgrade the Go/SSH and desktop build dependencies. Add dependency scanning and signing/notarization support to the build workflow.

Release prerequisites: signed macOS/Windows artifacts require configured repository signing credentials. Native administrator-dialog, routing and installation acceptance remains necessary on the target systems. No persistent kill switch is included; ordinary networking resumes after disconnect or cleanup.
