TunnelNest 1.2.6 adds native Linux ARM64 packages and fixes core-path overrides during administrator startup.

- Download linux-arm64 on aarch64/arm64 Linux machines; linux-x64 is for x86_64 machines.
- Build the engine and desktop on a native GitHub ARM64 runner and bundle checksum-verified ARM64 Xray and sing-box cores.
- Preserve explicit TUN and Xray binary paths when elevating a desktop connection instead of replacing them with bundled paths.
- Log the selected TUN helper path and give an actionable error when QEMU or a missing Linux loader prevents it from running.

Downloads include desktop and CLI archives for Windows x64, Linux x64, Linux ARM64, macOS Apple Silicon, and macOS Intel, plus SHA256SUMS.txt. Extract the entire archive and launch the app or CLI from its extracted folder.

Packages remain unsigned and macOS packages are not notarized. CI validates native executable startup and tests; live provider connectivity, graphical startup, and administrator-approved TUN routing still require testing on the target machine.
