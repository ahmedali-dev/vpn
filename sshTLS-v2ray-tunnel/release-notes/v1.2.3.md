TunnelNest 1.2.3 adds compact profile sharing and the Safe Flight identity.

- Share a saved SSH or V2Ray profile as a QR code, file, or compact code.
- Choose an optional share password. Password-protected exports use authenticated encryption; exports without a password are not encrypted.
- Import pasted codes, profile files, or QR images after validation. Imports create a new profile without connecting automatically or replacing existing profiles.
- Use a shorter compressed sharing format while keeping support for previous encrypted codes.
- Fix the desktop logo and include local QR generation and scanning without external services.

Download the desktop archive matching your system and extract the entire folder before launching. Windows includes Start-Tunnel.cmd and startup diagnostics. CLI bundles are separate. SHA256SUMS.txt covers all archives.

Packages are unsigned and macOS packages are not notarized. Native CI builds and automated tests do not verify interactive startup, live server connectivity, or full-device routing on every system.
