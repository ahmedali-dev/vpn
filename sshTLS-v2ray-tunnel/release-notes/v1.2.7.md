TunnelNest 1.2.7 updates Linux full-device traffic capture and startup verification.

- Enable sing-box auto_redirect on Linux, alongside auto_route and strict_route, while preserving upstream server exclusions.
- Test ordinary system-routed HTTPS after TUN activation, independently of environment HTTP proxies. Stop TUN and report an error if that check fails.
- Correct the connection banner after successful HTTPS checks.
- Validate generated SSH and Xray TUN configurations using the downloaded native sing-box executable on all five CI platforms.

Linux requires kernel support for nftables redirection. This update addresses a configuration gap suggested by logs where DNS was captured but application connections were absent; target-machine testing is still required to confirm the cause. Post-activation HTTPS checks verify connectivity, not leak protection.

Use linux-arm64 packages for aarch64 machines and linux-x64 for x86_64. Extract the entire archive. Packages remain unsigned and macOS packages are not notarized.
