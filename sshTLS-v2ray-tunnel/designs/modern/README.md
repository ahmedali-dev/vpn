# TunnelNest: three modern interface concepts

Open `index.html` to compare the three designs, or serve this directory with `python3 -m http.server 8765 --bind 127.0.0.1` and open http://127.0.0.1:8765.

1. **Verdant** — light green workspace, profile library, route map, and connection insights.
2. **Nocturne** — dark technical control room, lime accents, traffic chart, and profile cards.
3. **Solstice** — warm editorial layout, original orbital illustration, and a focused connection flow.

Each page supports profile selection/search/filtering, simulated connect/disconnect, routing mode, adding sample profiles, a log dialog/download, and design selection. Sample profiles reset when reloaded. Design preference is saved locally when localStorage is available. The choice does not modify the application; confirm the design number in chat before implementation.

All networking, locations, and statistics are illustrative. These pages do not call the application API or establish a VPN. No remote assets, fonts, dependencies, or build step are needed. Graphics are original inline SVG/CSS. Existing app files and older design studies are preserved.
